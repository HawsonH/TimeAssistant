## 5 重点边界与风险

### 5.1 AI 学习的默认值需要明显说明

学习开关默认开启，满足条件后会将脱敏证据发送给配置模型分析。主动 AI 与系统日历则默认关闭。用户可能将“本地智能库”理解为不发生网络请求，首次配置 AI 时应明确告知并提供选择。

证据: `LocalIntegrationSettingsStore.java:25`、`PreferenceLearningCoordinator.java:45`。

### 5.2 锁屏通知可展示任务名称

专注通知使用公开可见级别，扩展通知和标题可包含关联任务名。这有助于执行任务，但可能在锁屏展示敏感标题。建议增加应用级“锁屏隐藏任务名称”控制，并验证各厂商实际表现。

证据: `FocusTimerNotificationFactory.java:44`、`FocusTimerNotificationFactory.java:80` 附近。

### 5.3 局域网同步和导出并非加密备份

协议使用局域网 TCP 与 JSON 帧，配对码不是传输加密。JSON 导出也不做应用级加密。常规快照排除 API Key 和本地智能库，但仍包含任务、聊天和部分设备配置等隐私。

证据: `SYNC_PROTOCOL.md` 的 Transport、`AppRepository.java:761`、`AppRepository.java:1221`。

### 5.4 高频任务操作依赖左滑

普通列表卡片点击主要展示只读详情，编辑和完成依赖左滑。已有无障碍自定义操作是基础优势，但普通视觉用户可能没有发现左滑，建议提供可见的完成控件和更多菜单。

证据: `TimeAssistantActivity.java:4532`、`TimeAssistantActivity.java:4606`、`TimeAssistantActivity.java:4794`。

### 5.5 多个时间语义容易混淆

需要安排但信息不完整、普通待办、日程、待办倒计时、周期实例和专注正计时具有不同含义。特别是正计时仍有总时长、日程结束仍需完成确认，应在界面状态和操作结果中明确区分。

证据: `TimeAssistantActivity.java:2836`、`TimeAssistantActivity.java:3164`、`TimeAssistantActivity.java:4503`、`TimeAssistantActivity.java:5777`。

### 5.6 统一设计与维护仍有改进空间

主题基类为浅色 Material 主题，部分动态视图硬编码背景色和 10-12sp 文本，一些操作高度为 38-44dp。需要统一语义颜色、触控目标和字号适配，不应据此推断所有界面已经出现可见缺陷。

`TimeAssistantActivity.java` 当前为 8149 行，承担了大量界面、表单、AI 操作协调、计时和同步逻辑。已有 Controller 与 ViewModel 可作为渐进拆分基础，不必立即重写整套技术栈。

证据: `themes.xml:2`、`TimeAssistantActivity.java:2126`、`TimeAssistantActivity.java:3164`、各 PageController。
