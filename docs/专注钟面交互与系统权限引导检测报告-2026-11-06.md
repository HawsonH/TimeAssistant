# 专注钟面交互与系统权限引导检测报告

日期：2026-11-06，Asia/Shanghai。

## 实现

- 专注、短休、长休切换复用现有 Binding 和钟面，移除整钟及任务名重复入场。模式只做 220ms 局部淡变；分钟调整为 180ms 纵向与淡变。普通计时立即更新，不播放数字切换；相同目标不重启动画。
- 数字层由 `core:design` 的 `TimerTextTransition` 独立持有。连续调整截取当前可见文字层重新定向，不排队、不经过所有中间分钟；时钟外围、布局及刻度不移动。减少动效不超过 100ms 且无位移；关闭或系统关闭动画时立即到终态。离页、尺寸变化及后台停止并释放文字层和动画。
- 纯 Java `FocusDialGesture` 负责方向锁定、24dp/分钟、范围及取消判定；`FocusDialController` 负责触摸和无障碍事件，`FocusPageController` 持有生命周期。上划增加、下划减少，触摸预览、松手一次保存；回到原值不写入。专注 1–180 分钟，休息 1–60 分钟，上下限不累积越界距离。
- 多指、系统取消、离页、尺寸或准备状态变化均不提交；松手检查当前模式与已保存分钟数。页面刷新不覆盖预览。单击打开原详细设置，横向保留切换模式；运行和暂停不能修改时长。运行时真正移除加减与详细设置无障碍动作，返回准备状态再恢复。
- 正计时准备阶段显示计划时长，开始后仍按原规则从零计时；未改变开始、暂停、结算与统计规则。
- 新增“设置 > 系统权限与提醒”。`feature:settings` 只展示状态和事件，应用侧分别负责系统能力读取及 Activity Result/设置跳转。返回时刷新现有行，不重建表单。通知、任务渠道、持续专注渠道、精确闹钟、勿扰、后台/电池、麦克风和日历集中展示。
- 通知总开关与渠道声音/震动/横幅分开说明，补充 ColorOS 两层检查。未知厂商自启动、后台及锁屏设置标为需系统内确认。精确能力已有时不重复授权；只在用户点击后申请或跳转，日历授权不自动启用连接。系统页不可用时回退应用详情，再不可用时给出提示。测试通知复用既有诊断入口。
- 未修改数据库、通知渠道身份、计时持久化、OAuth、额度、凭据或清除业务数据。

## 修正与环境记录

- 首轮编译发现勿扰设置常量不是公开 API，改用公开声音设置入口并保留回退；Android 7 应用通知设置采用应用详情回退，消除新增 API 警告。
- 单元测试曾把“回到原分钟数”错误期望为提交，已修正为不提交；最终 9 项手势 JVM 均通过。
- 权限页 2 倍字体发现固定 48dp 的箭头文字裁切，改为最小高度及自然测量，64 组复测通过。
- 数字动效测试原来在 `seekTo` 同一调用栈要求框架动画已派发结束，改为验证目标帧和取消后资源释放，不删去终态断言。
- 既有逐帧测试首轮未捕获部分主题中间位置，后续串行复测通过。合成截图测试持续无焦点，补充焦点等待后确认模拟器实际被“System UI isn't responding”弹窗遮挡，证据 `build/focus-window-check.png`；正常关闭系统弹窗恢复后专项 1/1 通过。不以放宽断言代替恢复测试环境。
- 上述模拟器阶段无手机在线；随后手机重新连接，补验结果见下节。全程未调用 AI、登录、访问真实账号或修改手机权限。
