## 本轮实现

- 三种配置入口：官方 API Key、自定义中转、独立的 ChatGPT 账号登录扩展。
- 多连接新增、编辑、复制、删除、手动激活；复制不复制凭据。
- 显式选择 Chat Completions / Responses；获取模型、手动填写非 OAuth 模型、独立测试。
- 设置首页纵向分组、连接列表与详情、Material 输入框、Key 显隐及草稿离开确认。
- 聊天输入区显示连接与模型，可切换连接；历史入口与连接管理分离。
- 页面只接触配置和账号引用；凭据由执行端读取，页面状态不包含令牌。
- 公网 HTTPS、私网 IP HTTP 单独授权、无代理、拒绝重定向，OAuth 不使用 HTTP 例外。
- 官方 Responses 固定 `store:false`、`stream:true`，只有完整完成事件才交给提案解析。
- HTTP 鉴权/权限/额度错误及流中计划额度错误有应用自有文案，不回显任意服务端错误正文。
- 令牌轮换原子保存；登录、刷新、退出和清除凭据共用写入锁，防止旧后台操作写回已清除记录。
- 切换时取消请求并使旧客户端失效；旧聊天仍可查看，默认不发给新连接。

### 编译时移除 OAuth

```powershell
.\tools\Verify-Android.ps1 -Offline -Tasks @(
  '-PwithOpenAiOAuth=false',
  'checkModuleBoundaries',
  ':app:assembleDebug',
  ':app:testDebugUnitTest',
  ':core:domain:test',
  ':core:network:test'
)
```

该参数使 settings 不包含 OAuth 模块，app 改用 `src/oauthDisabled` 装配实现；
默认使用 `src/oauthEnabled`。无反射、无运行时插件加载。
移除后显示扩展不可用，不要求删除账号数据；官方 Key 和中转仍可使用。
默认构建重新运行 `.\tools\Verify-Android.ps1 -Offline`。

### 替换实现

兼容服务适配实现 `AiPort`，只接收配置引用、请求及取消信号。
账号扩展实现 `AiOAuthExtension`，由 OAuthModule 构造注入；必须同时实现取消登录、
串行刷新、注销和 `clearLocal` 写入排空，不把令牌交给页面或中转。
替换实现需更新模块依赖白名单，禁止依赖 app 或页面实现。

### 额度来源边界（2026-11-01）

最新真实直读验证状态：明确端点和凭据用途后，用户回复“允许”，随后已在手机执行一次 GET `chatgpt.com/backend-api/wham/usage`。当前 SIWC 令牌的受众为 `PUBLIC_API`、direct scope 存在，但没有可读账号 ID 声明，未发送猜测的账号头；实际返回 **HTTP 401、非 JSON**，未取得 5h/7d 窗口。没有响应正文原因，不能确定是受众、账号头或其他要求，也不推断额度为零或所有授权方式不可用。没有重试、借用 Codex 身份或进行推理。账号及活动连接保留。首次调用曾因未取得具体端点授权而被安全审查阻止，此历史不再代表当前未执行。证据见本日真机报告及 `official-quota-read-once.txt`。

用户优先选择官方额度直读。本轮未取得当前动态注册公共 API 授权的可用额度查询结果，故不声称已实现直读。官方文档提供 ChatGPT Settings → Usage 入口；应用将其放在账号页首位。生产代码不调用 `backend-api/wham/usage`；仅本次经明确授权的 QA 专项访问一次。不冒用 Codex 身份、不猜测授权范围、不把官方令牌传给 sub2api。后续确认可用端点与授权契约时，再以单独 `AiQuotaPort` 实现接入。

`AiQuotaPort` / `AiQuotaSnapshot` 位于纯 Java domain；`AiQuotaView` 位于 settings，只接受不可变数据，不接触 JSON、凭据或网络。现有可选 sub2api 来源由 `AiAuxiliaryServices` 注入来源和独立凭据到 `Sub2ApiQuotaPort`，仅发送 GET `/api/v1/admin/openai/accounts/{id}/quota`。移除 OAuth 实现不影响此模块。替换额度实现需要修改 app 的装配和解码适配；本轮尚未将整个辅助服务控制器改成全接口注入。

来源元数据一次提交，替换凭据使用不可变的新引用；先加密写入凭据，再提交元数据，提交失败保留旧来源。读取使用同版元数据和凭据引用，避免地址更新时向旧地址发送新凭据。旧 `aux:quota:{account}` 引用仍兼容。取消请求、来源版本检查及账号绑定确认防止过期结果覆盖新配置。只读缓存采用白名单投影，保留独立加密存储，不保存任意服务响应。

缺失数据不伪造为零；短/周窗口按时长而不是 primary/secondary 位置区分；相对重置时间只以服务端 `fetched_at` 为基准。接收时间不冒充服务更新时间，过期不在本机自动补满。余额保留十进制字符串精度；重置次数只读。没有新增 OAuth scope，也没有通过重复推理探测限额。

参考：OpenAI `https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions#tracking-usage`；sub2api `Wei-Shaw/sub2api` 提交 `d851a38477597157e78450d30af2d8504764d085` 的 `backend/internal/service/openai_quota_service.go` 与 `frontend/src/components/account/OpenAIQuotaResetCell.vue`。仅参考字段和展示语义，未移植其认证、重置消费或 TLS 指纹代码。

## 迁移与存储

任务 Room 数据库和业务快照版本本轮未升级。

旧单配置迁为稳定 ID `legacy-default`，新凭据先加密落盘，随后原子写入配置元数据，
最后标记迁移完成。中断后重试复用该配置，不重复创建；失败保留旧配置和 Key。
旧明文设置仅在迁移成功后清理，旧 Keystore 别名不改名、不销毁。

配置元数据在 `ai_connection_profiles`，加密凭据在 `ai_connection_credentials`。
新存储使用 Android Keystore AES-256-GCM，凭据引用作为 AAD。
新文件均从系统云备份和设备迁移中排除，不进入业务同步/导出。
官方注册、账号和 Key 使用不同引用，不共享可配置的认证来源。
删除/替换中转仅清理不再引用的 Key；清理失败不会误报已提交的配置保存失败。

非秘密草稿允许保存到 Bundle；Key 禁用 View 自动保存和 Autofill，
仅在 ViewModel 内存保留，不保证进程终止后的恢复。

## 官方登录边界

按本轮核对的 OpenAI 官方文档实现动态公开客户端流程，不使用 Codex 客户端身份、
客户端秘密、桌面注入或 ChatGPT backend-api。

固定官方认证来源，系统浏览器、127.0.0.1 随机端口 `/auth/callback`，
每次生成 state、nonce 和 PKCE。以实际签发的 client ID 换码并保存，
失败重试保留待完成注册 ID。Nimbus 验证签名、issuer、audience、
expiry、nonce 及返回账号 subject；模型调用另检查计划授权 scope。

刷新和注销在工作线程执行，后台缺授权返回失败，不打开登录页面。
正常退出尝试远端 revoke，失败明确提示本机已退出但远端未确认。
“清除全部本地数据”只保证本机清除，不宣称撤销所有远端授权。
回环监听在应用进程中；未过期会话可在重建后尝试恢复同一端口，端口不可用或会话过期时不得假装继续授权。进程被系统冻结时，前台服务也未必保证本机回调可响应，须保留真实设备验证门槛。

生产登录仅以官方 HTTPS 授权地址启动独立外部浏览器，不使用内嵌 WebView 或 Auth Tab。若回环页面超时，应保留页面并返回应用；会话仍有效时，可由用户在受保护的“完成浏览器授权”输入框本机粘贴地址，继续执行完整回调校验。不得把回调地址发到聊天、诊断日志或中转。该操作是恢复路径，不等于自动回调故障已修复。
