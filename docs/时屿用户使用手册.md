# 时屿用户使用手册

## 2026-11-08 页面样式更新

- 聊天、安排、专注的主标题采用统一层级；聊天连接与模型显示在标题下方，更多入口保持独立。
- 安排页先选择“日程 / 待办 / 注意”，再使用下方箭头或点击日期切换日期与月历。非今天显示“回到今天”；该操作仍保留原来的行为。
- 普通日程与周期日程使用相同的时间列和卡片间距。空列表显示统一空状态，不再重复显示创建操作的说明。
- 专注钟面按可用宽度显示，最大 320dp。准备态的“开始”和运行态的“暂停 / 继续”为主操作，“结束”为低强调危险操作；计时、滑动调时和暂停规则不变。
- “专注设置”改为纵向的计时、衔接、声振、记录四组；数字右侧标明单位，保存按钮固定在底部。锁屏设置通过普通导航行进入，未保存离开仍会询问。
- 输入框、任务卡和按钮采用统一圆角；聊天发送按钮不可用时降低透明度，不再用深灰实心抢占视觉。

本次仅更新界面和展示组件，未变更任务数据库、账号、授权或计时业务。模拟器与真机验收范围分别见《页面规范与布局统一检测报告-2026-11-08》。

## 2026-11-06 钟面交互与权限引导

- 未开始计时时，上划钟面增加分钟，下划减少分钟，每格调整 1 分钟。拖动时预览，松手才保存为该模式的默认时长；取消、多指或离页不保存。专注范围为 1–180 分钟，短休和长休为 1–60 分钟；开始后及暂停中不可修改本轮时长。
- 点击钟面打开详细时长设置，左右划动或点击模式选项切换模式。钟面不重新入场，只有时间数字局部过渡；完整动效有轻微纵向变化，减少动效仅淡变，关闭则立即更新。每秒计时不播放数字切换动画。正计时在准备阶段显示计划时长，开始后仍从零计时。
- “设置 > 系统权限与提醒”集中查看应用通知、提醒渠道、专注通知、精确闹钟、后台与电池、麦克风和日历状态。只有点击才申请权限或打开系统设置，返回后刷新状态，不自动录音、读取日历或启用日历连接。
- 声音、震动、横幅分别受应用总开关及通知渠道影响；ColorOS 等系统需检查两层设置。厂商自启动、锁屏和后台选项不能可靠检测时，显示需要在系统内确认，不代表已开启。测试提醒仍需亲自观察最终效果，应用不会覆盖旧渠道、静音或勿扰选择。

本轮修正版已覆盖更新现有“时屿 交互验收”，手机本地展示专项 9/9 通过，数据保留。真实权限交互、TalkBack 及长期后台仍待验，完整证据见《专注钟面交互与系统权限引导检测报告-2026-11-06》。

## 2026-11-04 注意、提醒与聊天更新

- 在“注意”勾选任务后，完成状态立即保存，原位置保留约 5 秒；期间再次点击可取消完成。辅助功能可能延长此时间。同一任务已被其他操作修改或删除时，不会强行覆盖新状态。旋转屏幕不重置缓冲时间，进程结束后不恢复撤销能力。
- 待办卡片及详情显示提醒日期和时间，截止时间单独标注。AI 的“几分钟后提醒”从确认执行后起算；绝对提醒时间显示在提案中。已有截止时间不会自动转换为倒计时。
- 提醒到点后发布系统通知，前台另有可关闭的提醒弹窗；多个提醒合并，不自动完成任务，不重复播放声音。在设置的“提醒诊断”中可检查权限、渠道、声音、震动、精确闹钟和后台限制，并发送测试通知。已有通知渠道设置保持不变，横幅、声音和震动仍取决于系统设置及勿扰状态。
- 发出文字和附件后，已提交内容立即从输入区清空，可以输入下一条。附件准备失败或取消时，空草稿自动恢复；已经输入新内容时保留新草稿，通过“恢复未发送内容”处理旧内容。消息已入历史后的模型错误不会重新填回输入区。
- 用户与 AI 气泡采用一致的文字间距，短文字自然收缩；长文件名最多显示两行并单列文件大小。结果中的撤销为低强调描边，“查看安排／进入专注”为文字操作，执行确认仍保留强调色。

本轮验证范围及未执行项见《注意缓冲任务提醒与聊天布局修复检测报告-2026-11-04》，不代表所有厂商后台、声音、震动与 TalkBack 场景已验收。

## 2026-11-02 交互更新

- AI 建议的正文、操作清单、逐项结果、撤销和查看入口保留在同一气泡中。失败项可重新确认，已成功项不会随重试重复执行；高影响操作仍需另行确认。
- 撤销仅对当前会话内且数据版本未变化的操作有效。旋转屏幕保留可用撤销，退出进程后不恢复；其他数据写入可能使撤销失效，气泡会说明原因。外部日历和偏好操作不提供整组撤销承诺。
- 安排页的“日程／待办／注意”通过一个滑动色块切换。减少或关闭动效后仍可正常切换；非今天日期的注意页限制不变。
- 左划先展开编辑与主操作，继续划动会增加阻尼、扩展主操作区域。触发确认反馈后松手执行；回划到阈值以下或取消手势不会执行。未开始的日程主操作是“开始”，进行中和普通待办是“完成”，已完成事项仍需确认撤销。
- 新建、编辑使用一致的日期时间控件。值旁的叉号清除单项，更多菜单可重置全部；备注和重复按需展开，收起不清空数据。“需要安排”沿用原排期含义，新建默认使用正在浏览的日期。
- “设置 > 主动整理”可独立配置每日 1–6 个待办整理时间，分别启停、改时和删除；注意页的四个检查时段单独保留。改动立即保存，只安排未来触发，不立即补发。
- 旧午间设置自动迁入一个整理时段，不自动扩大授权或开启关闭中的功能。每日上限、免打扰、专注避让和系统后台延迟仍适用；设置时间不代表精确闹钟。

时屿用于管理待办与日程、进行专注计时，并通过用户配置的 AI 服务辅助整理安排。建议先学会手动创建任务和专注计时，再按需要开启 AI、系统日历与设备同步。

涉及创建、修改或删除任务的 AI 建议，需要你在操作确认卡中确认后才会执行。AI 回复的文字不等于任务已经保存。

## 1 认识主要入口

| 入口 | 用途 | 常用操作 |
| --- | --- | --- |
| 聊天 | 描述需求、查看 AI 建议与聊天历史 | 输入文字、添加附件、语音转文字、确认操作 |
| 安排 | 查看和处理任务 | 切换日程、待办、注意，使用日历和右上角加号 |
| 专注 | 为任务或临时事项计时 | 选择任务、调整时长、开始、取消或结束本轮 |
| 通用设置 | 配置服务、偏好、连接和数据 | 聊天页右上角设置图标 |
| 专注设置 | 调整番茄节奏并查看记录 | 专注页右上角设置图标 |

通用设置首页使用纵向分组：外观与教程、AI 连接与账号、主动整理、安排偏好与通知、日历连接、同步与数据。专注设置仍有计时、衔接、声振、记录四个分类。

### 1.1 三种事项的区别

**待办**是不必占用具体时间段的事项，例如“买电池”。待办可设置倒计时提醒，提醒不代表占用了日程时间。

**日程**是具有完整开始和结束时间的事项，例如某天 09:00-09:30 的会议。

**未确定时间的任务**是需要安排时间，但尚未填完整开始和结束时间的事项。这类任务可能出现在“注意”，不是已经排好的日程。

### 1.2 无 AI 时可以做什么

不配置 AI 也可以手动管理任务和周期日程、使用专注计时、查看记录、设置本地提醒、导入导出数据，以及进行兼容设备间的局域网同步。

自然语言生成和修改安排、AI 拆分任务、AI 推断偏好等需要完成 AI 配置。语音识别是否需要联网取决于设备提供的识别服务。

## 2 第一次使用

首次新安装会显示安排、专注、AI 确认与隐私三步教程，可随时跳过。完成后首次进入相关页面会有情境提示；跳过不会创建任务、请求权限或开启 AI。进入“通用设置 > 外观与教程 > 重新体验新手教程”可重播。老用户不会被强制弹出教程，可从此入口体验。

### 2.1 先完成一条手动待办

1. 打开底部“安排”。
2. 切换到“待办”。
3. 点击右上角加号。
4. 输入“阅读项目资料”，可填写备注。
5. 点击“创建”。
6. 查看待办卡片上的完成复选控件。
7. 点击复选控件，将该待办标记为完成。

点击普通待办卡片通常打开只读详情；操作菜单提供编辑、进入专注和删除。原有左滑快捷操作仍保留。

### 2.2 创建一条日程

1. 在“安排”中切换到“日程”，点击加号。
2. 输入标题，例如“整理项目资料”。
3. 保持“需要安排”开启。
4. 选择日期，再分别选择开始和结束时间。
5. 确认结束时间晚于开始时间，点击“保存”。
6. 在对应日期的时间线中检查任务是否出现。

日期和时间允许暂时留空，但没有完整时间的任务不会因此成为已排好的日程。需要安排时间而信息不完整时，可去“注意”中继续处理。

**日期注意事项:** 从安排页新建日程或待办时，表单默认沿用正在浏览的日期，保存前可以调整。未指定日期的待办显示在今天；未来待办显示在目标日期，未完成的过去待办也保留在今天的积压列表。已完成待办按实际完成日期查看。

### 2.3 开始一轮专注

1. 打开底部“专注”。
2. 点击任务名称区域，选择关联任务，或保持不关联任务。
3. 未开始时点击圆环调整时长。
4. 点击“开始”。
5. 到时后，根据反馈选择任务已完成、开始休息、稍后休息或延期处理。

初次使用建议保留默认 25 分钟专注、5 分钟短休和 15 分钟长休。

## 3 配置 AI 服务

### 3.1 填写和验证配置

1. 从聊天页进入设置，选择“AI 连接与账号”。
2. 点击“添加连接”，选择“官方 API Key”或“自定义服务”。
3. 填写名称、地址、Key，明确选择 Chat Completions 或 Responses。
4. 点击模型输入框右侧的选择图标获取模型，或在非官方登录连接中手动填写模型 ID。
5. 点击“更多操作 > 测试连接”。测试只发送独立测试文本，不读取任务，不保存或激活连接。
6. 保存后，在连接列表打开该连接并选择“使用此连接”。
7. 返回聊天，核对顶部模型；点击模型可选择其他模型或切换连接。

服务必须支持所选协议，不会在失败后自动换协议或服务。Responses 连接要求服务返回完整的流式完成事件。模型 ID 必须是服务商实际提供且你的凭据有权限调用的模型。

公网服务必须使用 HTTPS。局域网 HTTP 仅接受私网或回环 IP 字面量，保存或测试前需要单独确认该 IP 与端口的风险授权；不接受域名 HTTP、代理或重定向。HTTP 不加密，API Key 和业务内容可能被网络上的其他人读取。可在 AI 服务页撤销全部局域网 HTTP 授权。不要将 API Key 放在聊天内容、截图、共享文档或反馈日志中。

### 3.2 多连接与草稿

| 操作 | 结果 |
| --- | --- |
| 测试连接 | 测试当前输入的配置，不等于保存 |
| 保存连接 | 保存配置，不自动将新配置设为当前连接 |
| 使用此连接 | 取消待完成请求并切换连接，后续聊天默认不发送旧连接上下文 |
| 复制 | 复制非秘密配置，不复制 Key 或账号授权 |
| 删除 | 删除选中的连接及其独立 Key，不删除任务、其他连接或官方账号 |

离开修改中的连接页面时，可保存、放弃或继续编辑。Key 草稿仅在当前进程内存中保留；进程终止后需要重新填写尚未保存的 Key。其他字段支持页面重建恢复。后台登录完成及连接状态更新不会退出正在编辑的连接，也不会覆盖未保存提示；地址和模型支持多行显示。

### 3.3 ChatGPT 官方登录

包含 OAuth 扩展的构建可从“AI 连接与账号 > 添加连接 > ChatGPT”发起官方登录。新版会打开独立的外部系统浏览器，不使用应用内授权窗口。登录与授权需要由你本人完成，应用不会代填账号或密码。

若浏览器的 `127.0.0.1` 页面超时，先保留该页面，再通过最近任务回到时屿。会话仍有效时，可在“完成浏览器授权”中本机粘贴该页完整地址并继续；不要把地址发给他人、聊天或中转。已过期则重新登录，旧地址不能继续使用。部分手机会限制后台运行，可点“登录后台运行设置”自行检查；应用不会自动更改系统限制。若使用旧版授权窗口且返回后页面消失，取消本次授权后再使用新版重新登录。

“AI 连接与账号 > 登录帮助”提供上述三步操作和有效会话的粘贴入口，11 月 1 日已安装到“时屿 设备验收”。大字体下可滚动阅读正文。回调会话有效期十分钟。手动粘贴完成后无需为了自动回跳再次登录。

授权后应用会获取该账号可用模型并准备连接；如未成为当前连接，可从账号菜单选择“使用此账号”，或在连接列表选择“使用此连接”。登录成功不代表已获得模型调用权限；未授权时需重新登录并检查授权范围。

官方连接只向官方服务发送官方令牌，中转只使用自己配置的 Key。切换至中转不会退出官方账号，也不会向中转转发官方令牌。

顶部模型菜单及 AI 设置提供“账号与用量”入口。本应用统计不等同于官方剩余额度；未配置额度来源时不会凭空显示额度。额度或权限错误时先检查用量和授权，不要反复重试。退出账号时会尝试撤销远端授权，再清除本机令牌；若提示远端撤销未确认，需要在 ChatGPT 设置中检查并断开应用。

11 月 1 日额度页面改造：账号页首先提供“查看官方用量”，在官方页面管理计划用量与本应用限额。当前官方登录授权没有已确认支持的额度直读接口，因此应用明确显示剩余比例、重置时间未知；不会尝试把公共 API 令牌发送到 ChatGPT 私有后台接口或中转。

“可选来源快照 · sub2api”仅供已有自己额度服务的用户使用，不是官方直读的必要步骤。来源地址、远端账号 ID、独立 Admin API Key／管理员 Bearer Token 均由用户单独配置，首次返回或账号变化需要核对绑定。不要填入 ChatGPT OAuth 令牌。只有点击“刷新来源快照”才查询，不消耗重置次数、不自动重试。

快照按服务实际窗口时长区分 5 小时、7 天或其他窗口，分别展示已用、剩余、重置时间、附加模型窗口及积分。未返回的值显示未知；积分不是金额。超过五分钟、更新时间不明或时间异常时提示历史快照；刷新失败不会把旧数据标成当前可用额度。已到快照重置时间也不会自动补满进度条，必须重新读取。收到快照的本机时间不能代替来源更新时间。本机 Token 统计、单应用限额和账号计划窗口必须分别看待。

10 月 31 日已通过本机手动粘贴完成首次真实授权并读取 8 个模型，但自动回跳仍未通过，一次固定文本推理返回计划使用受限，不能保证对话可用。遇到此提示先在“账号与用量”打开官方设置，检查计划用量与应用限额；不据此推断整个计划耗尽或重置时间，也不需要反复登录。官方 API Key 和自定义服务是独立选择，不会自动启用或代扣其他计费路径。

连接失败时，可进入“AI 错误日志”查看详情。提交反馈前仍应检查是否包含不宜公开的业务内容。

### 3.4 关于网络和数据

手动操作的主要数据保存在本机。启用 AI 后，你发送的聊天、附件，以及 AI 按需读取的任务、偏好或专注摘要等，会作为请求内容发送到你配置的服务。

“本地保存”不等于“启用 AI 后完全不联网”。AI 学习使用脱敏行为证据，也可能调用同一配置服务，详见第 10 节。

## 4 使用聊天整理安排

### 4.1 描述你的需求

可以尝试以下表达。示例展示表达方式，不保证每次生成完全相同的方案。

- “2026 年 10 月 14 日上午 9 点安排 30 分钟整理项目资料。”
- “把阅读计划拆成三个可执行的小任务，先给我确认。”
- “帮我检查明天的安排有没有时间冲突。”
- “把这个待办安排到明天下午，避开午休。”
- “我习惯上午处理写作，请给出安排偏好建议。”

有固定会议或不可调整的事项时，应在需求中明确说明。相对日期会按应用运行时的日期理解，确认前请检查生成的实际日期。

### 4.2 检查操作确认卡

AI 可以提出创建、修改、安排、拆分、完成、取消或删除任务，创建和调整周期日程，启动专注，修改问候语，以及偏好和系统日历相关操作。

1. 阅读每一步的任务名称、日期、时间和操作类型。
2. 只接受部分建议时，逐项点击“确认”。
3. 不需要的步骤可逐项“取消”。
4. 所有步骤都正确时，再使用“全部确认”或“确认剩余”。
5. 需要调整时继续对话，说明需要改变的内容。
6. 查看执行结果；失败的操作不能当成已经成功。

同类新提案可以替代旧的待确认提案；任务提案、偏好提案和外部系统跳转按类别处理。主动 AI 建议不会直接取消已有普通聊天提案。

删除、取消等破坏性操作可能要求再次确认。不要仅凭 AI 的自然语言回复判断执行结果。

### 4.3 查看 AI 读取了哪些数据

部分消息下方有“已读取若干类应用数据”。展开后可查看读取来源。这用于了解建议的依据，不代表 AI 自动读取了手机中的所有数据。

### 4.4 图片和文件

1. 点击聊天输入区旁的加号。
2. 选择文件或图片，检查待发送附件。
3. 输入希望 AI 处理的事项，再发送。

当前限制为一次最多 4 个附件，单个不超过 8 MB，合计不超过 16 MB。

应用会将附件发送给配置的服务，但能否理解图片、PDF 或其他文件取决于该服务与模型的支持情况。文件选择器允许选择文件，不代表所有格式都能成功处理。

聊天历史保存附件名称、类型和大小等元数据，不是附件原文件备份。导出聊天后不能依靠这些元数据恢复原附件。

### 4.5 语音输入

长按发送键可调用设备的语音识别。首次使用需要麦克风权限，授权后按提示再次长按。

识别结果进入输入框，检查文字后再发送。这不是持续语音对话，也不包含 AI 语音播报。设备没有可用识别服务时，请使用文字输入。

### 4.6 聊天历史

聊天页的日历入口可按日期查看历史会话。历史聊天仅供查看，不能在历史页面继续发送或确认旧操作；需要处理当前事项时先返回当前聊天。

会话不会在跨越午夜时强制立刻切断。跨日后，应用结合至少 2 小时未活动等条件判断是否开启新的日期会话。

## 5 管理日程和待办

### 5.1 日程视图

日程以所选日期的时间线展示。日期栏可切换前一天、后一天、选择日期或点击“今天”返回当天；右上角日历专门打开或关闭月历。

点击一般日程卡片可查看详情；可见完成控件用于完成或撤销完成，操作菜单用于编辑、专注与删除。周期日程的操作入口有所不同，见第 6 节。

时间线中的普通日程卡片还支持快速双击进入该任务的专注。左滑主操作会随状态显示开始、完成或撤销，不应把所有日程的第一个操作都理解为标记完成。

### 5.2 待办视图

待办不占用日程时间，适合记录尚不需要指定开始结束时间的事项。

可见复选控件用于完成或撤销完成，也可继续使用左滑快捷操作。已完成任务显示划线等状态。当前待办视图不是全部历史任务的搜索列表；历史日期展示该日完成以及计划在该日的待办。

### 5.3 待办倒计时和循环提醒

1. 新建待办时设置倒计时，或编辑已有待办并进入“提醒”分类。
2. 选择倒计时时长。
3. 需要重复提醒时开启“循环”。
4. 点击创建或保存，并允许系统通知。

循环会在到时后继续下一轮相同间隔的提醒，不会创建新的日程或新的任务副本。倒计时提醒和番茄专注计时是两个独立功能。

编辑已有倒计时时，只有重新设置时长才会重新计算目标时间；没有修改倒计时时，原来的目标时间继续保留。

### 5.4 编辑日程任务

日程任务详情分为基本、时间、操作。

- 基本: 修改标题、备注，以及是否需要安排到具体时间。
- 时间: 设置日期和开始结束时间，也可以清除。
- 操作: 开始、完成或撤销完成、延期处理、仅移除安排、删除任务，具体主操作随状态变化。

修改字段后点击“保存修改”。操作分类中的完成、移除安排等按钮会单独执行对应操作，不是仅修改表单草稿。

### 5.5 仅移除安排与删除任务

“仅移除安排”保留任务本身、标题、备注和截止日期，移除时间段并让任务回到待办；若仍满足逾期条件，也可能被归入“注意”。

“删除任务”移除任务及相关关系，执行后会提供立即撤销入口。当前不是长期回收站，关闭撤销窗口后，不应认为还能从回收站找回。重要内容请提前导出。

## 6 使用周期日程

### 6.1 创建

1. 在“安排”的日程页点击加号。
2. 填写标题及完整开始、结束时间。
3. 开启“周期日程”。
4. 点击规律选项设置重复方式与结束条件。
5. 保存后切换日期检查未来实例。

| 重复方式 | 示例 |
| --- | --- |
| 每 N 天 | 每 2 天运动 |
| 每 N 周 | 每 2 周复盘 |
| 每 N 月 | 每月整理资料 |
| 每个工作日 | 周一至周五晨间整理 |
| 每周多选 | 每周一、三、五学习 |
| 每月第 N 个星期几 | 每月第 2 个周一评审 |

结束条件包括永不结束、指定结束日期、指定重复次数。

这里的“工作日”按星期规则使用，不应当作已经支持法定节假日和调休识别。

### 6.2 修改和处理某一次

进入某次周期事项的菜单后，可以修改、跳过本次、恢复本次为系列规则、标记本次状态，或查看与结束系列。

修改时注意作用范围:

- 仅本次: 其他日期仍沿用原规则。
- 本次及以后: 调整该次及后续安排。
- 整个系列: 修改系列规则。

“跳过本次”不等于结束整个系列。“结束系列”停止后续周期，不删除已经开始或完成的历史任务。

周期组主要保存重复规律，并非一创建就生成无限任务；具体实例会在开始、完成或进入专注等处理时生成。

## 7 处理需要注意的事项

“安排 > 注意”是当前待处理问题汇总，只在浏览今天时可用。

| 分组 | 含义 | 建议处理 |
| --- | --- | --- |
| 逾期 | 已超过截止时间，或已经标记需要重新安排 | 编辑时间，或进入延期处理 |
| 待确认 | 日程已经结束，但完成结果尚未确认 | 选择已完成、未完成或稍后确认 |
| 未确定时间 | 需要安排时间，但开始结束信息不完整 | 补充日期和完整时间 |

任务日程结束后不会无条件自动变成已完成。选择“未完成”后会进入需要重新安排的状态；选择“稍后确认”则保留在待确认。

延期处理可选择请 AI 拆分、移至待安排、保留原时间稍后处理、降低优先级并待安排，或取消任务。其中 AI 拆分需要可用 AI 配置。

## 8 使用专注计时

### 8.1 模式和关联任务

未开始时可使用圆环上方的专注、短休、长休控件切换，也可左右滑动圆环。上下滑动每格加减一分钟，松手保存；点击圆环打开对应模式的详细时长设置。切换模式只过渡数字，不刷新整个钟面。

点击任务区域可选择日程或待办，也可以不关联任务，或使用临时任务名称。临时名称只用于本次专注标识，不等于创建了可管理的正式任务。

运行或暂停中的会话不能直接切换任务、模式或目标时长，需要先取消或结束当前轮次。

### 8.2 开始后的操作

| 操作 | 结果 |
| --- | --- |
| 暂停 | 保存本轮剩余时间，暂停期间不累计专注时间 |
| 继续 | 沿用同一会话继续计时，不创建第二条记录 |
| 取消 | 确认后恢复本轮初始计时，不计入本轮专注记录 |
| 结束并选择提前结束 | 保存已专注的时长 |
| 结束并选择任务中断 | 保存已专注时长，并可记录中断原因 |
| 自然到时 | 保存完成记录，并进入反馈或下一阶段流程 |

开始后主按钮变为“暂停”，暂停后变为“继续”。取消不等于暂停，结束也不等于完成整个任务。手动结束与自然到时通过统一结算入口处理，旧历史记录 ID 保持不变。

计时开始后，模式选项柔和收起，圆环放大并移至内容区域中部，操作区位于下方。未关联任务显示“自由专注”；任务较长时可换行，短屏和大字体可滚动。横屏左侧显示圆环、右侧显示任务与操作。

完整动效下，运行中的辅助内圈会轻微明暗呼吸，时间数字和真实进度不受影响；暂停时停止，继续后恢复。减少动效、关闭动效或系统关闭动画时不运行呼吸。后台和离开专注页也会停止展示动画，不影响业务计时。

### 8.3 正计时的边界

在“专注设置 > 计时”开启正计时后，显示的是本轮已用时间。当前仍沿用设定的本轮总时长，到达时长后结束，不是无限向上计时。

### 8.4 专注设置

| 分类 | 设置 |
| --- | --- |
| 计时 | 正计时或倒计时、番茄时长、短休时长、长休时长、长休间隔 |
| 衔接 | 结束后自动进入下一段、禁用休息、自动开始休息、自动开始下个番茄、结束提醒 |
| 声振 | 结束铃声、结束振动、专注环境音、锁屏番茄钟显示设置 |
| 记录 | 查看并删除专注记录 |

默认每 4 个番茄进入一次长休。自动进入下一段是父开关；关闭后，自动开始休息和自动开始下个番茄不会生效。禁用休息后，不再衔接短休或长休。

修改计时、衔接、声振设置后点击“保存专注设置”。删除专注记录不改变任务的完成状态。

四组内容纵向滚动，底部保存栏不随内容滚走；时长输入右侧显示“分钟”，长休间隔显示“番茄”。锁屏显示为带箭头的设置行，不是另一个保存按钮。

### 8.5 后台和锁屏

应用具有后台计时服务、结束处理及锁屏通知配置入口。实际通知显示受系统权限、通知渠道、锁屏隐私设置与厂商省电策略影响。

建议首次使用进行一次短时测试: 开始计时、锁屏、等待结束、返回应用检查记录。未验证前不要把它用于不能容忍漏提醒的关键事项。

“通用设置 > 偏好 > 通知中隐藏任务内容（含锁屏）”默认开启，专注通知仍显示计时与阶段，但不显示任务名称；普通提醒和主动建议也隐藏敏感内容。该设置即时生效，开启时会清除已显示的普通通知，并刷新当前专注通知。厂商系统实际显示仍需实机核对。

## 9 设置时间和提醒偏好

进入“通用设置 > 偏好”。

时间偏好包括每日可用时间、工作时间、不安排的时间段，以及是否允许 AI 调整未锁定任务。默认可用时间为 07:00-23:00，工作时间为 09:00-18:00。

不安排时间采用 `HH:mm-HH:mm`，多个时段使用逗号分隔，例如:

```text
12:00-13:00,22:00-07:00
```

这些是 AI 排程的约束输入，不是手机系统的免打扰设置。手动创建时间仍需自行检查。

### 9.1 提醒类型

| 类型 | 当前目标触发时机 | 设置入口 |
| --- | --- | --- |
| 日程开始提醒 | 开始前 10 分钟，前提是该时点尚未过去 | 通用设置 > 偏好 |
| 日程结束确认提醒 | 日程结束时 | 随日程提醒开关 |
| 截止提醒 | 任务截止时 | 通用设置 > 偏好 |
| 延期提醒 | 截止后约 15 分钟 | 通用设置 > 偏好 |
| 每日复盘提醒 | 每日 21:00 附近 | 通用设置 > 偏好 |
| 待办倒计时 | 设置的目标时间 | 待办编辑 > 提醒 |
| 专注结束提醒 | 本轮专注结束 | 专注设置 > 衔接 |

保存时间与通知偏好后，确认系统允许通知。任务提醒在具有精确闹钟授权时优先精确调度，未获授权时降级为可能延迟的非精确调度；每日复盘仍为非精确提醒。实际横幅、声音和震动由通知渠道、勿扰及系统限制共同决定。

## 10 管理 AI 学习和安排偏好

### 10.1 AI 学习

进入“通用设置 > 偏好 > AI 学习”。

当前“允许每日进入应用时分析一次”默认关闭。即使旧版曾开启，也需要新版风险说明中的明确同意。学习与主动整理分别授权；只有授权、AI 配置可用且证据满足条件时，才会请求分析，不是持续录音或持续读取屏幕。

分析使用脱敏的时间变化、项目、标签及操作结果等证据，可能发送到你配置的 AI 服务。需要限制这类请求时关闭学习开关。

“清除学习数据”删除行为证据和 AI 推断偏好，但保留手动创建的偏好。它不是删除全部任务或聊天。

### 10.2 手动和 AI 建议偏好

安排偏好可以表达偏好某个时间段，或避开某个时间段；可作用于全部安排、指定项目或指定标签。

1. 点击“新增偏好”。
2. 选择是否为需要避开的时间。
3. 输入开始和结束时间。
4. 需要限定范围时填写项目或标签名称，并选择名称类型。
5. 点击保存。

AI 推断的偏好需要确认后才会生效，也可以忽略。已有偏好支持编辑、启用、停用和删除。

明确设置的偏好优先于已确认的 AI 推断偏好，硬性时间约束仍优先。偏好中的项目或标签范围不代表当前已经具备完整项目管理界面。

## 11 开启主动 AI

主动 AI 是可选的实验能力，默认关闭，需要先完成 AI 配置。

1. 进入“通用设置 > 主动 AI”。
2. 开启“启用主动整理”。
3. 按需要调整每日节奏、整理内容、后台 AI、系统通知、频率和免打扰。
4. 可点击“立即检查一次”，触发一次午间整理逻辑。

默认节奏与限制:

| 项目 | 默认值 |
| --- | --- |
| 早间检查 | 08:30 |
| 午间检查 | 12:30 |
| 下午检查 | 16:30 |
| 晚间检查 | 21:00 |
| 每日消息上限 | 3 条，可调整为 1-6 条 |
| 免打扰 | 22:30-次日 07:00 |

早间、下午和晚间主要在注意页有事项时提供整理建议；午间还会检查未排期待办。没有符合条件的事项时，不会为了到点而发消息。

相同内容当天去重；达到每日上限、处于免打扰、正在专注或正在与 AI 对话时，可能跳过或延后。专注和对话忙碌时可延后约 30 分钟。手动立即检查也不绕过这些限制。

关闭“后台生成完整 AI 建议”后，只生成简短本地提示，不调用模型。保持开启可能产生服务商请求费用。

主动 AI 不会后台自动执行任务变更。对建议的任何修改仍需你确认。工作调度可能受系统影响，不能当作精确闹钟。

## 12 连接系统日历

进入“通用设置 > 连接 > 系统日历（测试）”。

1. 开启“允许 AI 查询系统日历忙碌时间”。
2. 允许读取日历权限。
3. 点击“测试读取”，检查未来 7 天忙碌区间读取是否正常。
4. 向 AI 提出避开系统日历忙碌时间的排程需求。

该功能默认关闭，只查询忙碌区间，不读取事件标题、描述、参与人或账户内容。忙碌区间可能作为排程上下文发送到配置的 AI 服务。

AI 还可提出预填系统日历事件。确认后打开系统日历编辑页面，你需要在系统日历中再次保存。应用显示“已打开系统日历”不代表事件已经创建。

当前不是系统日历双向同步，也不会无条件自动把全部应用日程写入系统日历。

## 13 设备配对与同步

进入“通用设置 > 数据 > 设备配对与同步”。

### 13.1 配对步骤

1. 将两台兼容设备连接到同一可信局域网。
2. 主设备点击“生成配对码”，记录显示的地址、端口和 6 位配对码。
3. 另一台设备点击“加入设备”。
4. 填写主机地址、端口和配对码，点击“配对并同步”。
5. 查看同步状态和上次同步时间，必要时点击“立即同步”。

默认端口为 `37681`。没有直接提供 IP 信息时，请从主设备网络设置查询局域网地址。

配对服务依赖应用进程和网络可达性，不要假定应用关闭后仍是永久在线服务。桌面端需要实现项目提供的同步协议，不是任意电脑都能直接连接。

### 13.2 同步范围与限制

同步涵盖任务、周期规则与例外、聊天、专注记录和相应设置等仓库数据。API Key 不同步；每台设备需自行配置凭据。

AI 学习证据、安排偏好数据库、主动 AI 开关及系统日历授权等本地智能数据，不随这条同步链路迁移。外观主题也是本机设置。

**安全边界:** 当前局域网同步传输未加密，6 位配对码不是加密密钥。不要在公共 Wi-Fi 上使用，不要把端口暴露到公网，也不要把配对信息公开分享。

“断开配对”不会删除本机已有数据。同步是数据合并，不是用于撤销错误操作的历史备份。

## 14 导出和导入数据

### 14.1 导出

1. 进入“通用设置 > 数据 > 数据管理”。
2. 点击“导出数据”。
3. 在系统文件界面选择保存位置。
4. 确认应用提示导出成功，并妥善保存 JSON 文件。

导出内容主要包括任务、周期规则与例外、提醒事件、聊天、专注记录、当前专注状态及应用设置。默认不包含 API Key，也不包含本地 AI 学习和安排偏好数据库。

导出文件未做应用级加密，可能包含任务标题、备注、聊天和设备同步元数据等敏感内容。不要作为公开附件发送。

### 14.2 导入

1. 先导出当前数据，保留恢复副本。
2. 点击“导入数据”，选择兼容 JSON 文件。
3. 选择替换或合并。
4. 导入后检查任务数量、周期日程、专注记录以及时间设置。

| 方式 | 用途 | 注意 |
| --- | --- | --- |
| 替换 | 恢复选定仓库快照 | 当前仓库内容可能被替换，先备份 |
| 合并 | 将导入内容与本机内容合并 | 相同 ID 不会简单复制成多个任务，冲突按版本信息处理 |

导入不会从文件恢复 API Key，也不会用文件中的 Key 覆盖本机凭据。新设备仍需自行配置 AI。

## 15 外观与清理

外观页保留暮紫、海蓝、松绿、暖陶四种配色，另可选择跟随系统、浅色或深色，均即时生效。“动态效果”支持完整、减少和关闭，同时遵守系统动画设置。长任务名称允许换行；四配色、大字号和横屏的设备验收尚未完成。

| 清理操作 | 保留内容或后果 |
| --- | --- |
| 清除 AI 配置 | 任务保留，AI 需重新配置 |
| 清除学习数据 | 任务和手动偏好保留 |
| 清除聊天记录 | 任务、日程和专注记录保留 |
| 删除单条专注记录 | 任务完成状态不变 |
| 清除全部本地数据 | 删除核心数据、本地智能数据、配对信息及 AI 配置，需要二次确认 |

清除全部本地数据不可自动恢复。普通 JSON 导出不涵盖所有本地智能数据，因此不要把导出文件当作整机完整备份。

## 16 常见问题

### 16.1 说了需求却没有生成任务

先确认 AI 配置已保存且连接可用，再检查是否有待确认操作卡。AI 可能只回复建议、询问补充信息或返回错误，文字回复不会直接保存任务。

### 16.2 任务没有出现在日程中

确认查看日期正确、开始结束时间完整，且任务不是已取消状态。需要安排时间但信息不完整的任务可去“注意”查看；普通待办不会自动占用时间线。

### 16.3 找不到编辑或完成按钮

使用普通任务卡片上的完成控件或操作菜单，也可向左滑动。菜单中的编辑进入表单，复选控件处理完成或撤销完成。“注意”页的卡片也可能直接打开对应问题处理流程。

### 16.4 主动 AI 没有发消息

依次检查总开关、AI 配置、是否有符合条件事项、免打扰、每日上限、当日去重及当前专注或对话状态。立即检查没有消息也可能是正常结果。

### 16.5 通知或锁屏计时没有显示

检查应用提醒开关、系统通知权限、对应通知渠道、锁屏通知显示与省电设置。具体系统页面因手机品牌而异。短时测试后仍异常时，记录机型、系统版本、权限状态和触发时间再反馈。

如果已有通知但没有横幅、声音或震动，进入“设置 > 安排偏好与通知 > 任务提醒诊断”。诊断显示“未允许横幅”“已静音”或震动“已关闭”时，可通过“提醒渠道设置”按自己的意愿调整。更新应用不会覆盖旧渠道的静音或低优先级选择；“已提交系统通知”不等于手机实际响铃或震动。

部分 ColorOS 手机有两层开关：先在系统的应用通知首页开启“铃声”和“振动”，再从下方“类别 > 任务与日程提醒”检查默认铃声及该渠道的独立振动。应用级振动开启不代表渠道振动已开启；若渠道页最初只有“允许通知／静默通知”，开启应用铃声后返回并重新进入检查。横幅需单独选择，勿扰和静音设置仍然生效，不需要开启“允许打扰”来完成普通提醒测试。

### 16.6 文件或图片发送失败

先检查数量、单个大小和总大小，再确认服务与模型是否支持该类附件。可以尝试更小图片或直接发送文字。不要反复上传含敏感内容的大文件进行盲测。

### 16.7 配对失败或无法同步

确认同一局域网、IP 和端口正确、配对码保留前导零、主机配对服务仍在运行。部分访客网络会隔离设备。没有实现协议的桌面软件不能直接参与同步。

### 16.8 一轮番茄结束后，任务为什么没自动完成

专注轮次完成不等于任务完成。关联任务需要在结束反馈中选择“任务已完成”，或者在安排页手动标记。

## 17 推荐日常流程

2026-11-04 专注交互更新：点击开始后，模式选项柔和退场，钟表和操作区平顺移动；取消或结束返回准备状态时恢复。暂停/继续不重复移动。减少动效仅淡变，关闭动效或系统关闭动画时直接显示结果，不影响实际计时。

早上打开“安排”，检查今天的日程和注意事项，补全时间不完整的任务。临时想法先记入待办，不必急着排期。

开始工作前挑选一项任务进入专注。到时记录实际结果，未完成事项可以延期或请求 AI 拆分，不必用取消本轮代替正常结束。

需要 AI 帮助时，明确时间和约束，检查操作确认卡后再执行。晚上查看专注记录与未完成事项；重要调整前先导出数据。
