# 时屿模块替换说明

更新日期：2026-10-18。本文仅说明已实现的模块边界，不宣称完整架构改造完成。

10 月 18 日新增 AI 连接模块与可移除 OAuth 装配，完整表格、构建命令、
迁移边界及剩余差距见 [AI 连接与 OAuth 扩展](./AI连接与OAuth扩展.md)。
下表保留教程改造时的基础模块说明；当前依赖规则以根构建脚本白名单为准。

## 当前模块

| 模块 | 当前职责 | 允许的项目依赖 |
| --- | --- | --- |
| core:domain | 纯 Java 教程状态、待办日期归属策略 | 无 |
| core:serialization | JsonInterop 映射 | 无 |
| core:design | 外观偏好、动效规范、外观控件、计时环 | 无 |
| core:navigation | TutorialFeature、TutorialFactory、语义锚点注册 | 无 |
| engine:ai | AI 客户端、提案解析与传输策略 | core:serialization |
| integration:calendar | 日历权限检查、忙碌区间读取与编辑器跳转 | 无 |
| feature:onboarding | 三步教程、版本化本机进度、情境提示 | core:domain、core:design、core:navigation |
| app | Android 入口、AppGraph、尚未提取的页面/仓库/引擎与集成 | 装配所需模块 |

包名保留以减少调用迁移噪声；源码只存在于所属模块，不在 app 重复保留副本。计时环由页面注入语义调色板，不引用应用 R 或业务仓库。日历权限策略接收明确的用户开关，不引用应用设置实现。

## 替换教程

1. 在新的 Android library 中实现 `TutorialFeature`，只依赖导航契约和所需核心模块。
2. 在应用装配处将 `TutorialCoordinator::new` 替换为新 `TutorialFactory`。不支持运行时插件。
3. 页面只注册 `GuideTarget`，不读取教程内部 View ID；替换实现必须遵守 initialize、replay、onStart、onStop、dispose 生命周期。
4. 无教程构建可注入各方法为空操作的实现，并删除 app 对 feature:onboarding 的依赖。当前教程独立于任务、网络和权限，不能代替用户操作。

## 验证

运行 `.\tools\Verify-Android.ps1 -Offline`。首次缓存不完整时不传 `-Offline`。脚本只临时修改进程环境变量，结束后还原。

`checkModuleBoundaries` 检查非 app 模块的项目依赖白名单，并拒绝 core:domain 导入 Android 或 org.json。AGP 自身依赖不计作业务模块依赖。增加新模块必须同时更新白名单，不能借 app 反向依赖绕过检查。

## 尚未完成

完整业务模型仍在 app，模型与 JSON 尚未完全分离。data:local 已提取 AI 配置存储；feature:settings/chat 已提取本轮连接界面，但未迁完原有页面业务。engine:focus/proactive、integration:sync/backup 和其他业务页面模块尚未提取。TaskReadPort、TaskWritePort、FocusSessionPort 等完整端口未建立，Activity 仍含大量业务代码。

页面 ViewModel 已改为构造注入 LiveData，但它仍是旧 AppState 的过渡读取方式，不是最终细粒度页面状态。AppGraph 尚未形成全部端口装配。不能据当前模块数量宣称 AI、日历、同步全部可删除替换；替换实现回归测试仍需补齐。
