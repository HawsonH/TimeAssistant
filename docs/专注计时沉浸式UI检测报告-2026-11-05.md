# 专注计时沉浸式 UI 检测报告

日期：2026-11-05，Asia/Shanghai。

## 实现与边界

- 采用“偏沉浸视觉＋轻微呼吸反馈”，不增加统计卡片、励志文案或新全屏入口。
- 竖屏使用上下弹性留白分配可用高度，运行中计时环目标 320dp，上限 336dp；短屏先缩减至可用直径，内容仍不足时滚动，不缩小文字掩盖溢出。操作区距内容底部至少 24dp。
- 圆环增加细刻度及低对比度内圈。时间采用固定 sp 层级；大字体或长时间显示分成分钟数字与秒数，不按屏幕宽度缩小字号。横屏采用左侧圆环、右侧任务和操作。
- 运行中的无关联任务改为“自由专注”，临时任务不再显示选择箭头；关联任务可换行。计时中不再向无障碍用户提供调整时长、切换模式的不可用动作。
- 暂停/继续采用柔和主题底色，结束采用描边；深色更多图标使用 AppCompat 着色。
- 新增独立 `RingAmbientMotion`：4.8 秒完整周期，只有辅助内圈透明度在 6%–14% 之间变化；主进度、数字、按钮和布局不呼吸缩放。仅 RUNNING、FULL、前台可见时执行，暂停柔和回静态，停止/离页释放动画。每次计时刷新不重启周期。
- 圆环展示通过 `PresentationState` 与业务计时隔离，排版由 `TimerDialText` 负责，视口测量由 `FocusViewport` 负责，状态和生命周期由 `FocusPageController` 管理。保留现有 240ms 开始/返回过渡及 `MotionSpec` 短动画时长上限。
- 未修改计时、结算、提醒、数据库、OAuth、额度或凭据规则。没有新增动画库。
