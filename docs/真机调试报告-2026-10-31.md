## 发现与处理

1. **横屏专注首屏不可用**：原纵向布局使计时数字与开始按钮落到首屏外。新增 `layout-land/page_focus.xml`，采用计时环与操作区左右布局，大字体时保留滚动；不修改专注规则。新增控件完整可见性断言，防止只验证控件存在。
2. **测试权限前置条件**：14 项最初因 ColorOS 拒绝 ADB 授权失败。改为先检查已有权限，正常系统 UI 授权后重跑；不能把前置条件失败直接算作业务失败或通过。
3. **周期单次修改偶发 Activity 销毁**：权限修复后的首次重跑出现一项 `Activity has been destroyed already`；单独重跑及完整 86 项批次通过。保留稳定性观察，未认定已找到业务根因。
4. **浏览器系统确认**：两次回环超时被“时屿 QA 想要打开 Chrome”确认框阻挡。正常选择“仅本次允许”后回调和 Auth Tab 返回通过，没有修改系统限制。
5. **截图遮挡**：固定 16:00 的测试日程在实际 17:00 后触发结束确认。改为未来两小时的虚构日程并选中对应日期，重新采集；遮挡截图不能视为完整视觉验收。
6. **主机与脚本**：修复 PowerShell 字符串将类名列表变成空格分隔的问题；增加无线重连等待、日志实时落盘和按原设备身份恢复显示设置。一次 Gradle JVM 因本机原生内存不足退出，单 worker、1024MB 堆重试通过；未终止其他应用或修改系统内存配置。
