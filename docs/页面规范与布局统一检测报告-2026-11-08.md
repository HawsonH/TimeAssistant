# 页面规范与布局统一检测报告

日期：2026-11-08，Asia/Shanghai。本报告仅覆盖本轮界面改造，不表示历史完整改造计划已全部交付。

## 实现范围

- `core:design` 集中提供容器/输入/按钮 12dp、全圆分段/芯片及小标签 6dp 的形状规范，任务横划裁剪和前景共用容器圆角。主页面标题、正文、次要文字采用 20/16/13sp 层级；计时数字等专用组件保留独立字号。
- 三个主入口统一标题行与 48dp 操作入口。聊天当前连接和模型位于标题下方；未连接入口使用分组行。不可发送时保持强调色并降低到 40% 透明度。
- 安排页先分段、后日期，左右切日与点击月历保留；“回到今天”仅在非今天可见，今天保留其布局槽位，避免日期和按钮来回挤压。日期行视觉收紧，但仍保留 48dp 触控区，没有为满足 40dp 行高而降低可访问性。
- 普通和周期日程共用 `ScheduleTaskLayout`：起止时间列基准 56dp，大字体时按实际文字测量扩展，不把时分拆行；卡片内边距 16dp、边界 12dp。周期保留自己的系列操作和例外标识，不改变三种修改范围。
- 专注钟面按页面可用宽度的 72% 约束且不超过 320dp；准备/运行复用同一尺寸规则。竖屏移除用于撑高的权重 Space，采用固定间距；横屏保留左钟右控件。开始、暂停/继续为主操作，结束为低强调危险操作，任务关联行统一背景。
- `FocusSettingsLayout` 只负责滚动内容、四组展示和固定保存栏；原页面继续负责草稿与保存。数字输入按字体测量可用宽度并显示单位，行高自然增长；锁屏配置为普通导航行，不再与保存形成两个主按钮。
- 日程、待办、注意、聊天空状态共用 `UiKit.emptyState`，不重复创建说明。聊天、附件、提案、任务表单和现有底部面板的圆角使用共享规范。
- 未修改数据库版本、任务/周期身份、计时结算规则、通知渠道、OAuth、额度或任何凭据。没有新增真实服务请求。

## 截图可信性与环境问题

每张页面截图先检查预期文字、实际 View 可见且有窗口焦点，再读取系统 `mCurrentFocus` 确认属于交互验收包，最后保存屏幕截图。若为系统弹窗、桌面或其他应用则中止，不把图片当作通过证据。

- 首轮模拟器被 System UI 无响应弹窗遮挡，已保存 `build/ui-consistency-window.png` 和窗口 XML；按正常系统按钮关闭后恢复。保留历史失败日志，不删除或覆盖为成功。
- 测试工具在 Activity 重建后偶尔无法获得无障碍根节点，改为页面焦点与系统窗口交叉检查。`dumpsys window windows` 不包含当前版本的焦点字段，随后改为完整 `dumpsys window` 并严格检查应用包名；没有放宽前台要求。
- 深色循环最初恢复了上次专注页，而非测试预期的聊天页；脚本改为显式进入每个目标页，不修改应用的页面记忆行为。
- 回归批次漏传 `physicalFixtures=true`，8 个横划/提案用例在安全前置检查被拒绝，未执行该批业务动作。仅针对无账号的 `emulator-5560` 重新显式授权假数据运行，未移除隔离包、无连接/账号/凭据等保护检查；结果独立记录。
- 补跑时发现第三条写死旧 16dp 圆角的裁剪宽度断言，改为引用共享规范。该次有 1 个失败，随后修正重跑，不能隐藏为首轮通过。
- 关闭动画专项结束后，缺失的系统配置不能恢复成字符串 `null`；临时显式开启动画补跑色块中间帧，结束后删除临时键以恢复缺省。此过程仅修改自建模拟器，未修改手机系统设置。
- 截图中的系统日期可能与报告的 Asia/Shanghai 日期不同：模拟器使用自己的时区，本轮不为截图修改系统日期或业务时间。

## 图像复核后的修正

- 初轮流程通过不等于画面没有问题。人工复核 2 倍字体截图发现固定时间列把 `18:38` 拆开，已改为按实际文字宽度扩展且保持单行，新增大字体单行与完整文字宽度断言。
- 横屏运行钟面存在数字重影。源码定位为每 250ms 计时更新复用文字过渡入口；现在普通计时只平滑进度环，文字立即反映真实值，模式/滑动/详细设置仍使用独立文字过渡。新增普通计时不得创建 outgoing 文字快照的断言，未改变计时频率和结算。
- 大字体钟面按实际字形边界而非包含不可见 leading 的整行度量居中排布，保留明确 sp 字号和必要分行，避免状态贴到圆环边缘。
- `UiManualCaptureTest` 由点击旧分类胶囊改为滚动到分组；`FullFeatureWorkflowTest` 的衔接保存流程移除过时的胶囊点击。旧圆角和钟面上限断言分别跟随共享容器圆角和 320dp 上限，原手势/数据断言保留。
- 原图保留为初轮证据；修正后图以 `corrected-` 前缀区分，旧重影或拆行图片不作为修正后通过证据。

## 未验收与限制

- 当前 ADB 没有在线手机。本轮未覆盖安装真实手机，不新增、卸载或清除任何手机应用；不接触现有账号。
- TalkBack 人工朗读/手势、真实手机触感、帧率性能、键盘完整矩阵，以及厂商系统页仍待验。
- 本轮模拟器展示与交互通过不扩大为后台计时、锁屏通知、声音、振动或真实 AI 授权通过。
- 尺寸、字体和五主题是分组采样，不宣称所有配置的完整笛卡尔积均进行系统级切换；上下文绘制矩阵与真实屏幕截图分开记录。
- 系统版本覆盖仅 API 36。历史同步、备份、OAuth 及其他未完成项不在本报告中标记完成。
